MallBuddy

AI-Powered Smart Mall Navigation & Assistant

An intelligent mall platform integrating indoor navigation, store discovery, promotional offers, and an AI-powered conversational assistant.

  • Developed graph-based A* shortest-path navigation considering spatial structure, floor boundaries, and walking paths.
  • Built REST APIs for dynamic management of mall layouts, stores, navigation waypoints, and offers.
  • Implemented RAG using mall-specific information stored in a vector database for contextual assistance.
  • Focused on modularity, scalability, and strict data consistency between navigation graph and database.
